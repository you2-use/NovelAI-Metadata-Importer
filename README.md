# NovelAI Metadata Importer

NovelAI로 만든 이미지에 남아 있는 생성 설정을 **Marinara Engine의 NovelAI 연결 설정으로 가져오는 확장**입니다. 이미지를 선택하면 현재 설정과 가져올 설정을 비교하고, 필요한 항목만 골라 적용할 수 있습니다.

- **확장 버전:** v1.0.0
- **대상 프로그램:** Marinara Engine v2.5.0
- **설치 방식:** GitHub 확장 관리자 또는 ZIP 직접 설치

[v1.0.0 ZIP 다운로드](https://github.com/you2-use/NovelAI-Metadata-Importer/archive/refs/tags/v1.0.0.zip) · [릴리스 안내](https://github.com/you2-use/NovelAI-Metadata-Importer/releases/tag/v1.0.0)

## 어떤 기능인가요?

NovelAI 연결 편집기의 **NovelAI 생성 설정** 제목 옆에 **가져오기 아이콘**을 추가합니다. 이 버튼에서 메타데이터가 보존된 PNG·WebP 이미지를 열어 모델, 프롬프트, 샘플러 등의 설정을 가져올 수 있습니다. 선택한 이미지를 연결 목록의 썸네일로 등록하는 기능도 제공합니다.

한국어·영어 화면과 Marinara의 밝은·어두운 테마를 지원합니다. 엔진 소스를 수정하거나 npm을 설치하고 코드를 빌드할 필요 없이 사용할 수 있습니다.

## 설치 전 준비

두 설치 방법 모두 Marinara에서 외부 확장이 허용되어 있어야 합니다. 이미 외부 확장을 사용하고 있다면 다음 설치 단계로 넘어가세요.

1. 서버에서 외부 확장이 잠겨 있다면, Marinara 설치 폴더의 `.env` 파일에 `ENABLE_EXTERNAL_EXTENSIONS=true`를 설정한 뒤 Marinara를 재시작합니다. 다른 사람이 운영하는 서버를 사용한다면 서버 운영자에게 설정을 요청하세요.
2. **설정 → 고급 → 위험 구역**에서 **타사 확장 가져오기 허용**을 켭니다.
3. **설정 → 애드온 → 외부 확장**에서 확장을 가져옵니다.

가져온 확장은 처음에 꺼진 상태로 저장됩니다. 코드를 검토하고 요청 권한을 승인한 뒤 켜야 사용할 수 있습니다. 언어 팩에 따라 일부 버튼은 영어로 표시될 수 있습니다.

## 설치 방법 1: GitHub 확장 관리자

GitHub 확장 관리자가 설치되어 있고 켜져 있는 경우 사용할 수 있습니다.

1. GitHub 확장 관리자에서 **확장 추가**를 누릅니다.
2. GitHub 저장소 주소 입력란에 아래 주소를 붙여 넣고 **패키지 찾기**를 누릅니다.

   ```text
   https://github.com/you2-use/NovelAI-Metadata-Importer
   ```

3. 설치할 패키지에서 **manifest.json**을 선택하고 **내용 확인**을 누릅니다.
4. 확장 이름이 **NovelAI Metadata Importer**, 버전이 **v1.0.0**인지 확인합니다. 코드를 확인한 뒤 **설치**를 누릅니다.
5. **검토 후 켜기**를 누르고, Marinara의 확인창에서 코드와 **전체 페이지 접근** 권한을 검토한 뒤 실행을 승인합니다.

공개 저장소이므로 설치하는 사람은 GitHub에 로그인하거나 토큰을 입력할 필요가 없습니다. 이후 업데이트도 이 저장소 연결로 확인할 수 있습니다.

## 설치 방법 2: ZIP 다운로드 후 직접 설치

GitHub 확장 관리자 없이 Marinara의 기본 가져오기 기능으로 설치할 수 있습니다.

1. **[v1.0.0 ZIP 다운로드](https://github.com/you2-use/NovelAI-Metadata-Importer/archive/refs/tags/v1.0.0.zip)**를 눌러 파일을 받습니다. 이 ZIP에는 설치에 필요한 `manifest.json`, `extension.js`, `extension.css`가 들어 있습니다. **ZIP을 미리 풀 필요는 없습니다.**
2. Marinara에서 **설정 → 애드온 → 외부 확장 → 확장 파일 가져오기**를 엽니다. 영어 화면에서는 **Import Extension File**입니다.
3. 다운로드한 `.zip` 파일을 선택합니다.
4. 가져오기 화면에서 **NovelAI Metadata Importer** 항목과 버전을 확인하고 가져오기를 완료합니다.
5. 추가된 확장의 **검토 및 실행 / Review and run**을 열어 코드와 **전체 페이지 접근** 권한을 확인한 뒤 실행을 승인합니다.

GitHub 확장 관리자가 기본 가져오기 버튼을 숨긴 경우에는 관리자의 **확장 추가 → 파일에서**로 같은 ZIP을 선택할 수 있습니다. ZIP으로 설치한 확장은 GitHub 업데이트 확인을 이용하려면 관리자에서 저장소를 별도로 연결해야 합니다.

## 사용 방법

1. Marinara에서 사용할 **이미지 생성 연결**을 열고, 서비스가 **NovelAI**인지 확인합니다.
2. **NovelAI 생성 설정** 제목 옆의 **가져오기 아이콘**을 누릅니다. 아이콘에 마우스를 올리면 **가져오기** 툴팁이 표시됩니다.
3. **PNG 또는 WebP 이미지 선택**을 눌러 이미지를 고르거나, 가져오기 창의 파일 영역에 이미지를 끌어다 놓습니다.
4. **현재 설정**과 **가져올 설정**을 비교하고 적용할 항목만 선택합니다.
5. 모델의 Full·Curated 구분을 확인할 수 없는 이미지라면 **가져올 모델 선택**에서 원하는 변형을 선택합니다. 선택하지 않으면 현재 모델을 유지합니다.
6. **적용**을 누릅니다.
7. 연결 편집기에서 결과를 확인하고 **Marinara의 저장 버튼**을 눌러 설정을 저장합니다.

**가져오기 창의 적용 버튼은 편집 중인 값을 바꿉니다. 생성 설정을 보관하려면 마지막에 Marinara의 저장 버튼을 눌러야 합니다.** 취소하면 가져온 설정을 반영하지 않습니다.

### 가져오는 설정

| 항목 | 동작 |
| --- | --- |
| 모델 | 지원되는 모델 정보가 있으면 가져옵니다. Full·Curated 구분이 불명확하면 직접 선택합니다. |
| 단계 | 이미지의 생성 단계 수를 가져옵니다. |
| 프롬프트 가이던스 | 이미지의 가이던스 값을 가져옵니다. |
| 가이던스 리스케일 | 이미지의 리스케일 값을 가져옵니다. |
| 프롬프트 접두사 | 이미지의 기본 프롬프트를 가져옵니다. 선택하면 기존 접두사를 교체합니다. |
| 네거티브 접두사 | 이미지의 네거티브 프롬프트를 가져옵니다. 선택하면 기존 접두사를 교체합니다. |
| 샘플러 | 이미지의 샘플러를 가져옵니다. |
| 노이즈 스케줄 | 이미지의 노이즈 스케줄을 가져옵니다. |

메타데이터에 없는 항목이나 선택을 해제한 항목은 현재 값을 유지합니다. 스타일 프로필, 캐릭터 수에 따른 해상도, 스타일 참조 등은 변경하지 않습니다.

**생성 설정을 하나 이상 적용할 때 시드는 항상 `-1`, UC 프리셋은 항상 `0`으로 설정됩니다.** 이미지에 저장된 시드와 UC 프리셋 값은 복사하지 않습니다. 따라서 가져온 설정을 사용하더라도 원본 이미지가 그대로 재현되지는 않습니다. 캐릭터별 프롬프트와 원본 해상도는 자동 적용하지 않습니다.

### 이미지를 연결 썸네일로 등록하기

가져오기 창의 설정 표 아래에 있는 **이미지를 썸네일로 등록하기**를 켠 뒤 **적용**을 누르면, 선택한 이미지가 현재 연결 목록의 썸네일로 등록됩니다. 기존 썸네일이 있으면 교체합니다.

- 토글은 처음에 꺼져 있습니다. 다른 이미지를 선택하면 다시 꺼집니다.
- 썸네일은 **적용할 때 바로 서버에 저장**됩니다. 생성 설정은 별도로 Marinara의 **저장** 버튼을 눌러야 합니다.
- 생성 설정 항목을 모두 해제하고 썸네일 토글만 켜면, 시드·UC를 포함한 생성 설정을 바꾸지 않고 사진만 등록할 수 있습니다.
- 토글을 켤 수 없다면 연결에 고유한 이름을 지정해 먼저 저장하고, 연결 목록에서 해당 연결을 다시 선택한 뒤 가져오기를 열어보세요.

## 지원 이미지와 제한

- **PNG:** 일반 텍스트 메타데이터와 NovelAI의 숨겨진 알파 채널 메타데이터를 지원합니다. 숨겨진 정보는 8비트 RGBA·비인터레이스 PNG를 지원합니다.
- **WebP:** EXIF UserComment에 생성 정보가 보존된 정지 이미지를 지원합니다. PNG로 변환할 필요가 없습니다.
- **크기 제한:** 파일 최대 32 MiB, 이미지 최대 16,777,216픽셀, 압축 해제된 메타데이터 최대 1 MiB입니다.
- 브라우저의 기본 압축 해제 기능을 사용하므로 이를 지원하는 Safari·Chrome 계열 브라우저가 필요합니다.

JPEG, 움직이는 WebP, 메타데이터가 제거된 이미지, 스크린샷에서는 원래 생성 설정을 복구할 수 없습니다. 메신저나 이미지 편집 프로그램을 거치면 메타데이터가 사라질 수 있으므로 NovelAI에서 받은 원본 파일을 사용하는 것이 좋습니다. XMP에만 정보가 있는 WebP와 WebP 알파 채널에만 숨겨진 정보는 지원하지 않습니다.

## 권한과 데이터 처리

이 확장은 **전체 페이지 접근(`full_page_access`)** 권한을 요청합니다. NovelAI 연결 편집기에 버튼을 넣고 기존 입력란에 설정을 반영하기 위해 필요합니다. 전체 페이지 접근 권한은 Marinara 페이지와 현재 세션의 내부 API에 접근할 수 있는 권한이므로 코드를 확인한 뒤 승인하세요.

이미지 메타데이터는 브라우저 안에서 분석하며 외부 서비스로 이미지를 보내지 않습니다. 연결을 식별하기 위해 현재 Marinara 서버의 연결 목록을 조회합니다. 썸네일 등록을 선택하면 브라우저에서 작은 PNG 썸네일을 만들어 **현재 Marinara 서버**에 저장합니다. 원본 파일은 변경하지 않으며, 썸네일에는 원본 메타데이터와 프롬프트를 포함하지 않습니다.

확장을 끄거나 삭제해도 이미 저장한 연결 설정과 썸네일은 유지됩니다.

## 업데이트와 수정 기록

GitHub 확장 관리자로 설치했다면 해당 확장의 **업데이트 확인**에서 새 코드를 확인하고 **업데이트 설치**로 갱신할 수 있습니다. ZIP 직접 설치는 새 버전 ZIP을 받아 같은 가져오기 화면에서 기존 확장을 업데이트하세요. **Save Disabled Update**가 표시되면 비활성 상태로 업데이트를 저장하는 버튼입니다.

업데이트 후에는 확장이 꺼진 상태로 저장됩니다. 새 코드를 검토하고 다시 실행을 승인하세요. 전체 페이지 확장을 갱신한 뒤 화면 상태가 남아 있으면 새로고침하세요.

새로 설치한 v1.0.0은 수정 기록 **0개**로 시작합니다. 수정 기록은 각 사용자의 Marinara에 저장된 코드 편집·업데이트 이력입니다. GitHub 커밋 수와는 별개이며, 이미 설치한 확장의 기록이 새 배포로 초기화되지는 않습니다. README만 추가하거나 수정해도 실행 코드는 바뀌지 않습니다.

## 문제 해결

| 증상 | 확인할 내용 |
| --- | --- |
| 외부 확장 메뉴가 없거나 가져오기가 잠겨 있어요. | 서버의 `ENABLE_EXTERNAL_EXTENSIONS=true` 설정과 위험 구역의 타사 확장 허용을 확인하세요. |
| 가져오기 아이콘이 보이지 않아요. | 확장이 승인·활성화되어 있는지, 연결 서비스가 NovelAI인지 확인하고 페이지를 새로고침하세요. |
| 메타데이터를 찾지 못해요. | NovelAI 원본 PNG 또는 EXIF 정보가 보존된 WebP를 선택하세요. |
| 모델이 자동으로 바뀌지 않아요. | 모델 항목을 선택했는지 확인하세요. Full·Curated 구분이 없으면 직접 선택해야 하며, 정보가 충돌하거나 지원되지 않으면 현재 모델을 유지합니다. |
| 썸네일 토글을 켤 수 없어요. | 연결을 고유한 이름으로 저장하고 목록에서 다시 선택하세요. 서버 연결 상태도 확인하세요. |
| 적용한 설정이 저장되지 않아요. | 가져오기 창의 적용 후 연결 편집기의 저장 버튼도 눌렀는지 확인하세요. |
| 입력 칸을 찾을 수 없거나 부분 적용 안내가 나와요. | 연결 편집기를 다시 열고 재시도하세요. 저장하기 전에 각 값을 확인하세요. Marinara 버전이 바뀌었다면 호환성 업데이트가 필요할 수 있습니다. |

문제가 계속되면 [이슈 페이지](https://github.com/you2-use/NovelAI-Metadata-Importer/issues)에 Marinara 버전, 확장 버전, 브라우저와 오류 문구를 알려주세요. 공유하는 이미지에 프롬프트 등 개인적으로 보관할 정보가 들어 있는지 먼저 확인하세요.

## 파일 구성

```text
NovelAI-Metadata-Importer/
├─ manifest.json   # 확장 이름·버전·권한·파일 경로
├─ extension.js    # 이미지 메타데이터 읽기와 설정 반영
├─ extension.css   # 버튼과 가져오기 창 스타일
└─ README.md       # 설명과 설치·사용 안내
```

실행에 필요한 파일과 의존성이 포함되어 있어 별도 설치·컴파일 과정이 없습니다.
